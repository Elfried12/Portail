Utilisation de l'intelligence artificielle

Par souci de transparence, un assistant IA  a été utilisé comme aide sur certaines parties du JavaScript jugées plus complexes :



Recherche et filtres : fonction de débounce et logique de filtres combinables

Modals : délégation d'événements sur les grilles et restitution du focus à la fermeture

Navigation : détection de la section visible avec IntersectionObserver

Formulaire : regex de validation (nom, téléphone international)

Sécurité : fonction escapeHTML() pour éviter l'injection de code lors de l'affichage des données
